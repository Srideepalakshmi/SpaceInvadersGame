# SpaceInvadersGame
Space Invaders is a Java-based game where players use a spaceship to shoot at incoming aliens, with the game logic, graphics, and sound managed through Swing components.

# Space Invaders (Java Swing Game)
## How to Run
1. Clone the repo:
   git clone "https://github.com/Srideepalakshmi/SpaceInvadersGame.git"
2. Open the project in any IDE (IntelliJ, Eclipse, VS Code).
3. Compile and run:
   javac SpaceInvadersGame.java
   java SpaceInvadersGame

## Features
- Multiple levels
- Score tracking
- Enemy movement & shooting
